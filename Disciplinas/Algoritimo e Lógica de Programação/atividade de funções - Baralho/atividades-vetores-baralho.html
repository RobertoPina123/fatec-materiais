🎯 Atividades
01

A Fileira Humana — Declaração e Acesso

⏱ 15–20 min 👥 Turma toda Índice · Acesso · Declaração

Os alunos são o vetor. Cada um vira uma posição (índice), segurando uma carta como seu valor. O professor faz chamadas de código e a turma executa.

  • 01Embaralhe um baralho. Distribua 1 carta (face para baixo) para 13 alunos que ficam em fila numerada de 0 a 12.
  • 02Diga: "vetor[3]" → o aluno na posição 3 vira a carta e mostra o valor. Anote no quadro.
  • 03Peça atribuições: "vetor[7] = ás de espadas" → o aluno troca sua carta.
  • 04Tente acessar "vetor[13]" — ninguém responde. Discuta: acesso fora do limite!
  • 05Peça ao professor auxiliar anotar o vetor no quadro conforme as cartas são reveladas.
Conceito fixado: Vetores têm tamanho fixo, índices começam em 0, acessar fora do limite causa erro — tudo isso fica visceral quando você é a posição 13 que não existe.
// O que está acontecendo em código:
int vetor[13]; // 13 alunos em fila
vetor[3] = 7; // aluno[3] mostra carta 7
vetor[13] = 1; // ❌ sem aluno aqui! Erro.
02

Percorrendo com o Dedo — Laço sobre Vetor

⏱ 20–25 min 👥 Grupos de 5–7 For · Percurso · Acumulador

Cada grupo recebe 7 cartas enfileiradas face para baixo. Um aluno faz o papel do índice i, percorrendo a fila enquanto outro "executa o corpo do laço".

  • 01Distribua 7 cartas embaralhadas para cada grupo (use os dois baralhos para atender os ~5 grupos).
  • 02Aluno "i" começa na posição 0 e aponta para cada carta sequencialmente.
  • 03Missão A: Somar os valores numéricos (A=1, J=11, Q=12, K=13) — aluno "acumulador" vai somando em voz alta.
  • 04Missão B: Encontrar a maior carta — aluno "max" segura a maior vista até agora.
  • 05Ao final, cada grupo traduz o processo em pseudocódigo no papel.
Discussão: Por que i vai de 0 até 6 (não até 7)? O que acontece se parar antes? E se começar em 1?
int soma = 0, max = cartas[0];
for (int i = 0; i < 7; i++) {
  soma += cartas[i];
  if (cartas[i] > max) max = cartas[i];
}
03

Ordenando na Mão — Bubble Sort Visual

⏱ 25–30 min 👥 Grupos de 6–8 Ordenação · Swap · Laço aninhado

Alunos em fila seguram cartas e executam o Bubble Sort com seus próprios corpos — trocando de lugar quando a lógica manda.

  • 016 a 8 alunos em fila, cada um com uma carta virada para a turma.
  • 02Professor "executa" o algoritmo: compara alunos adjacentes ("posição i vs i+1").
  • 03Se estiverem fora de ordem → os dois alunos trocam fisicamente de lugar (swap!).
  • 04A turma de fora conta as trocas e anota cada "passada" do laço externo.
  • 05Rodar 2–3 vezes com grupos diferentes. Compare: quantas trocas cada configuração precisou?
Pergunte: Qual é o pior caso? (cartas em ordem inversa.) Melhor caso? (já ordenadas.) Introduz complexidade de forma intuitiva.
for (i = 0; i < n-1; i++)
 for (j = 0; j < n-i-1; j++)
  if (v[j] > v[j+1]) { // troca de lugar!
   temp=v[j]; v[j]=v[j+1]; v[j+1]=temp;
  }
04

Busca do Mistério — Busca Linear e Binária

⏱ 20–25 min 👥 Duplas competindo Busca Linear · Busca Binária · Eficiência

Uma dupla busca a carta-alvo com busca linear, outra com busca binária (baralho já ordenado). Quem encontra com menos "comparações" vence.

  • 01Prepare duas fileiras de 13 cartas: uma embaralhada (para busca linear), uma ordenada (para binária).
  • 02Revele a carta-alvo (ex: "7 de ouros"). As duplas começam ao mesmo tempo.
  • 03Busca linear: percorre da esquerda, virando uma a uma até achar.
  • 04Busca binária: vira a do meio → se maior vai à direita, se menor à esquerda → repete.
  • 05Contar em voz alta quantas cartas foram viradas em cada método. Anotar no quadro para 5 rodadas.
Insight poderoso: Com 13 cartas, a busca binária precisa de no máximo 4 comparações. Com 52 cartas, ainda ~6. A turma "sente" o O(log n) antes de aprender a notação.
05

Desafio do Croupier — Codificação em Grupo

⏱ 30–40 min 👥 Times de 4–5 Consolidação · Lógica · Pseudocódigo

Atividade de fechamento: cada time recebe um baralho e um desafio para resolver primeiro fisicamente com as cartas, depois em pseudocódigo/código.

  • 01Distribua 10 cartas por grupo e um cartão com o desafio (veja abaixo).
  • 02O grupo resolve com as cartas físicas primeiro, documentando cada passo.
  • 03Traduz para pseudocódigo ou código na linguagem da disciplina.
  • 04Apresenta para a turma o processo e o código. Outros grupos testam com cartas diferentes.

♥ Desafio A

Separar as cartas vermelhas das pretas em dois vetores distintos. Imprimir quantas de cada naipe.

♠ Desafio B

Encontrar todas as cartas com valor par e colocá-las no início do vetor, mantendo a ordem relativa.

♦ Desafio C

Inverter o vetor de cartas sem usar outro vetor (in-place). Mostrar antes e depois.

♣ Desafio D

Contar quantas cartas de cada naipe existem. Armazenar as contagens num segundo vetor de 4 posições.

♠ ♥ ♣ ♦
💡 Dicas para o Professor

🎴 Gestão dos Baralhos

Com 2 baralhos (104 cartas) você atende ~5 grupos simultâneos com ~10 cartas cada com folga. Separe os baralhos por cor de fundo para nunca misturar.

📋 Valores padrão

Combine antes: A=1, J=11, Q=12, K=13. Escreva no quadro durante toda a aula para evitar dúvidas durante os exercícios.

⚡ Ordem recomendada

Atividade 1 (turma toda) → 2 (grupos) → 3 (grupos) → 4 (duplas, opcional) → 5 (desafio, fechamento). Adapte ao tempo disponível.

🔗 Ponte para o código

Sempre anote no quadro o equivalente em código de cada ação física. O aluno que vira a carta na posição 3 é o vetor[3].

📊 Avaliação rápida

Na Atividade 5, circule pelos grupos e peça para qualquer membro explicar qualquer linha do pseudocódigo — ótimo indicador de compreensão real.

🔄 Variações futuras

As mesmas dinâmicas servem para matrizes (cartas em grade), pilhas (pilha de cartas na mão) e filas — o baralho vai longe na disciplina!
